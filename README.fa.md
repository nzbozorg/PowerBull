## ✨ پاوربول چیه؟

خراب شدن یه دکمه نباید کار کردن با کل گوشی رو سخت کنه.

پاوربول دکمه‌های پرکاربرد گوشی رو توی یه منوی شناور جمع‌وجور و ویجت‌های صفحهٔ اصلی در اختیارت می‌ذاره. چه دکمه‌های فیزیکی گوشیت خراب شده باشن، چه فقط بخوای راحت‌تر با گوشی کار کنی، کنترل‌های ضروری فقط یه لمس باهات فاصله دارن.

رنگ‌های سرمه‌ای، قرمز و طلایی، در کنار یه طراحی خلوت، کمک می‌کنن دکمه‌ها دم دست باشن؛ نه دست‌وپاگیر.

## 🎛️ چه دکمه‌هایی داری؟

| دکمه | کاری که انجام می‌ده |
| --- | --- |
| 🔒 قفل صفحه | با قابلیت رسمی دسترس‌پذیری اندروید، گوشی رو قفل و نمایشگر رو خاموش می‌کنه. |
| ⏻ منوی پاور | اگه گوشی اجازه بده، منوی پاور خود اندروید رو باز می‌کنه. |
| 🔊 صدای بیشتر | صدای موزیک و ویدیو رو زیاد می‌کنه. |
| 🔉 صدای کمتر | صدای موزیک و ویدیو رو کم می‌کنه. |
| 🏠 خانه | می‌برتت به صفحهٔ اصلی گوشی. |
| ↩️ برگشت | همون کار دکمهٔ برگشت اندروید رو انجام می‌ده. |
| ▣ برنامه‌های اخیر | فهرست برنامه‌های اخیر رو باز می‌کنه. |

> **مهم:** پاوربول نمی‌تونه گوشی کاملاً خاموش رو روشن کنه، نمایشگر خاموش رو بیدار کنه یا قفل گوشی رو دور بزنه. اگه دکمهٔ پاورت خرابه، قبل از خاموش کردن کامل گوشی، مطمئن شو راه مطمئنی برای روشن کردن دوباره‌ش داری.

## 🫧 یه پنل کوچیک، به سلیقهٔ خودت

- **فقط آیکون، بدون شلوغی:** منوی شناور متن اضافه نداره.
- **بکش و جابه‌جا کن:** دکمه با یه انیمیشن به نزدیک‌ترین لبه می‌چسبه.
- **جاش رو یادش می‌مونه:** سمت و موقعیت عمودی دکمه ذخیره می‌شه.
- **دکمه‌ها رو خودت انتخاب کن:** فقط یه دکمه بذار یا چندتا؛ حداقل یه گزینه باید فعال بمونه.
- **ظاهرش رو تنظیم کن:** میزان دیده‌شدن پنل از **۳۰ تا ۱۰۰ درصد** و اندازهٔ دکمه از **۴۴ تا ۷۶ دی‌پی** قابل تغییره.
- **کم‌رنگ شدن خودکار:** اگه بخوای، دکمه بعد از چند ثانیه استفاده نشدن کم‌رنگ می‌شه.
- **لرزش موقع لمس:** بازخورد لمسی رو روشن یا خاموش کن.
- **تغییر پیوستهٔ صدا:** روی دکمهٔ صدای منوی شناور نگه دار تا صدا پشت‌سرهم تغییر کنه.
- **تنظیمات دم دست:** روی حباب نگه دار یا آیکون تنظیمات پنل رو بزن.

برای بردن یه دکمه به آخر پنل، توی بخش **شخصی‌سازی** خاموشش کن و دوباره روشنش کن. آیکون‌های تنظیمات و بستن همیشه توی پنل بازشده در دسترسن.

## 🧩 ویجت‌های جداگانه برای صفحهٔ اصلی

برای هرکدوم از هفت کار می‌تونی یه ویجت مستقل بذاری؛ از یه میان‌بر قفل صفحه تا چند دکمه با کارهای مختلف. هر ویجت انتخاب خودش رو نگه می‌داره.

از بخش **ویجت‌ها** توی پاوربول اضافه‌شون کن، یا از فهرست ویجت‌های لانچر گوشیت. پشتیبانی از افزودن مستقیم، اندازه و تغییر اندازه به لانچر بستگی داره.

## 🌍 فارسی یا انگلیسی؛ انتخاب با توئه

با دکمهٔ **فا / EN** کنار شمارهٔ نسخه توی نوار بالا، زبان رو عوض کن.

متن‌های فارسی روان و خودمونی نوشته شدن و چیدمان محتوای فارسی راست‌به‌چپه. انتخاب زبانت ذخیره می‌شه. کنترل‌ها، توضیحات راه‌اندازی، پیام‌ها، پنجره‌ها و اسم کارهای ویجت هم ترجمه شدن.

## 📥 نصب و شروع کار

۱. فایل `PowerBull-1.0.1-universal-release.apk` رو از بخش **Releases** همین مخزن بگیر.

۲. فایل رو باز کن. اگه اندروید خواست، به همون مرورگر یا فایل‌منیجر اجازهٔ نصب بده. فقط از منبعی نصب کن که بهش اعتماد داری.

۳. پاوربول رو باز کن و مراحل راه‌اندازی رو انجام بده:
- دسترسی **نمایش روی برنامه‌های دیگه** رو فعال کن.
- توضیحات دسترس‌پذیری رو بخون و اگه موافق بودی، **کنترل‌های پاوربول** رو توی تنظیمات دسترس‌پذیری اندروید روشن کن.

۴. برگرد به برنامه و توی بخش **کنترل‌ها**، گزینهٔ **دکمهٔ شناور** رو روشن کن.

۵. روی حباب بزن تا باز شه، بکش تا جابه‌جا شه و از **شخصی‌سازی** مطابق سلیقه‌ت تنظیمش کن.

### آپدیت از نسخهٔ 1.0.0

نسخهٔ رسمی 1.0.1 رو مستقیم روی نسخهٔ قبلی نصب کن. شناسهٔ برنامه و کلید امضا تغییر نکردن؛ لازم نیست نسخهٔ قبلی رو پاک کنی و تنظیماتت حفظ می‌شن.

### 🔐 تنظیمات محدودشدهٔ اندروید

توی بعضی گوشی‌های اندروید ۱۳ به بالا، دسترس‌پذیری برای برنامه‌های نصب‌شده خارج از فروشگاه محدود می‌شه. اگه اندروید جلوی فعال کردن پاوربول رو گرفت، این مسیر رو بررسی کن:

**تنظیمات گوشی ← برنامه‌ها ← PowerBull ← منوی سه‌نقطه ← اجازه دادن به تنظیمات محدودشده**

بعد برگرد به تنظیمات دسترس‌پذیری. اسم و جای گزینه‌ها ممکنه روی گوشی‌های مختلف فرق کنه. فقط وقتی این اجازه رو بده که به فایل APK اعتماد داری. پاوربول خودش هیچ دسترسی‌ای رو فعال نمی‌کنه.

## 🛡️ دسترسی‌ها و حریم خصوصی

| دسترسی | چرا لازمه؟ |
| --- | --- |
| نمایش روی برنامه‌ها | برای نشون دادن حباب و پنل شناور روی برنامه‌های دیگه. |
| سرویس دسترس‌پذیری | برای اجرای قفل صفحه، منوی پاور، خانه، برگشت و برنامه‌های اخیر؛ وقتی خودت دکمه‌شون رو می‌زنی. |
| تغییر تنظیمات صدا | برای کم و زیاد کردن صدای رسانه؛ معمولاً پنجرهٔ اجازهٔ جداگانه نداره. |

**گوشی خودته، اطلاعاتت هم همین‌طور:**

- بدون تبلیغ، تحلیل رفتار، ردیاب و حساب کاربری.
- بدون دسترسی `INTERNET`؛ خود برنامه اطلاعاتی ارسال نمی‌کنه.
- بدون خوندن محتوای صفحه، زیر نظر گرفتن فعالیت‌ها، تایپ کردن یا ضبط صفحه.
- سرویس دسترس‌پذیری اشتراک رویدادهای صفحه نداره؛ کاری رو اجرا می‌کنه که خودت انتخاب کردی.
- تنظیمات روی گوشی خودت می‌مونن و پشتیبان‌گیری برنامه غیرفعاله.
- هر وقت بخوای می‌تونی دسترسی‌ها رو از تنظیمات اندروید قطع کنی.

دکمهٔ حمایت، مرورگر رو باز می‌کنه. سایت حمایت مالی، قوانین حریم خصوصی خودش رو داره.

## ⚠️ محدودیت‌هایی که بهتره بدونی

- **اندروید ۹ یا بالاتر لازمه.** قفل صفحه از قابلیت رسمی دسترس‌پذیری استفاده می‌کنه؛ نه روت و نه دسترسی قدیمی مدیریت دستگاه.
- **یونیورسال یعنی مستقل از معماری پردازنده؛ نه تضمین همهٔ گوشی‌ها.** برنامه کتابخانهٔ بومی مخصوص یه پردازنده نداره، ولی محدودیت سازنده، پروفایل کاری و نسخه‌های مختلف اندروید می‌تونن روی عملکرد اثر بذارن.
- **منوی پاور با خاموش کردن اجباری فرق داره.** گزینه‌های قابل نمایش رو اندروید و سازندهٔ گوشی تعیین می‌کنن.
- **دکمه‌های صدا برای رسانه‌ان؛** نه کنترل اختصاصی صدای تماس، زنگ یا آلارم. بعضی دستگاه‌های صوتی و سیاست‌های سیستم هم تغییر صدا رو محدود می‌کنن.
- **روی بعضی صفحه‌های امن، پنل شناور پنهان می‌شه؛** مثل بعضی درخواست‌های دسترسی و برنامه‌های حساس.
- **محدودیت باتری ممکنه روی در دسترس بودن دکمه اثر بذاره.** اگه ناپدید شد، دسترس‌پذیری و تنظیمات اجرای پس‌زمینهٔ گوشی رو بررسی کن.
- **بعد از روشن شدن دوبارهٔ گوشی،** ممکنه لازم باشه اول قفلش رو باز کنی تا سرویس دسترس‌پذیری شروع به کار کنه.

جزئیات بررسی‌ها و فهرست تست‌های پیشنهادی توی [TESTING.md](TESTING.md) هست. موفق بودن ساخت، بررسی امضا و بررسی ایستا به معنی تست شدن روی همهٔ گوشی‌ها نیست.

## 🛠️ ساخت از روی سورس

### ابزارهای لازم

| بخش | نسخه |
| --- | --- |
| زبان برنامه‌نویسی | Java |
| JDK | 17 |
| حداقل اندروید | 9 / API 28 |
| Compile / Target SDK | 35 |
| Android Build Tools | 35.0.0 |
| Android Gradle Plugin | 8.7.3 |
| Gradle Wrapper | 8.9 |
| شناسهٔ برنامه | `com.powerbull.app` |

پروژه رو با Android Studio باز کن و SDKهای لازم رو نصب کن. برنامه وابستگی اجرایی شخص ثالث نداره.

```sh
# ساخت نسخهٔ توسعه
./gradlew assembleDebug

# بررسی ایستای اندروید
./gradlew lintRelease

# بررسی سورس و منابع ترجمه با پایتون ۳
python3 tests/verify_update.py
```

توی ویندوز به‌جای `./gradlew` از `gradlew.bat` استفاده کن.

### 🔑 ساخت ریلیز امضاشده

کلید خصوصی و رمز امضا **جزو سورس عمومی نیستن**.

تنظیم فعلی Gradle، فایل کلید رو توی `signing/powerbull-release.jks` با نام مستعار `powerbull` و رمزش رو توی متغیر محیطی `PB_STORE_PASSWORD` می‌خونه. برای نسخهٔ مستقل خودت، کلید خودت رو بساز؛ کلید خصوصی نگه‌دارندهٔ پروژه رو درخواست یا منتشر نکن.

```sh
# بعد از آماده کردن کلید محلی و متغیر محیطی
./gradlew assembleRelease
```

مسیر خروجی: `app/build/outputs/apk/release/app-release.apk`

نسخه‌ای که با کلید متفاوت امضا شده، روی APK رسمی آپدیت نمی‌شه. آپدیت‌های رسمی باید شناسه و کلید قبلی رو نگه دارن و `versionCode` رو افزایش بدن.

## 🤝 گزارش مشکل و مشارکت

مشکلی دیدی یا ایده‌ای داری؟ توی همین مخزن یه Issue باز کن. برای گزارش باگ، این‌ها رو هم بنویس:

- مدل گوشی و نسخهٔ اندروید.
- نسخهٔ پاوربول و زبان انتخاب‌شده.
- مراحلی که مشکل رو ایجاد می‌کنن، چیزی که انتظار داشتی و چیزی که اتفاق افتاده.
- اگه کمک می‌کنه، تصویر یا ویدیو؛ اطلاعات شخصی رو قبلش حذف کن.

برای تغییرهای بزرگ، بهتره قبل از فرستادن Pull Request، ایده رو توی یه Issue مطرح کنی. حریم خصوصی، دسترس‌پذیری، جمع‌وجور بودن کنترل‌ها و پشتیبانی هر دو زبان رو در نظر بگیر.
